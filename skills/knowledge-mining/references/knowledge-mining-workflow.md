# Knowledge Mining Workflow

## Extraction Grid

| Dimension | Extract |
|---|---|
| Entity | Organizations, people, products, institutions, locations |
| Event | Dated actions, filings, announcements, changes, incidents |
| Issue | Problems, risks, opportunities, constraints, controversies |
| Claim | Verifiable statement with source IDs |
| Pattern | Repeated relationship across claims |
| Asset | Reusable framework, table, visual, brief, dataset, checklist |

## Reuse Classification

- `reusable-public`
- `reusable-internal`
- `client-specific`
- `sensitive`
- `stale-watch`
- `retired`

## Refresh Cadence

| Claim type | Refresh trigger |
|---|---|
| Law/regulation | New official notice or effective date |
| Market data | New release, quarter, or major shock |
| Entity profile | Filing, leadership change, ownership change |
| Risk judgment | New indicator or contradiction |
