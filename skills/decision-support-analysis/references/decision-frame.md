# Decision Frame

## Minimum Decision Definition

| Field | Requirement |
|---|---|
| Decision | Specific choice to be made |
| Owner | Person or body with authority |
| Deadline | Date or event that forces timing |
| Stakes | What changes if the decision is wrong |
| Default | What happens if no active choice is made |
| Constraints | Budget, legal, ethical, operational, timing |
| Success criteria | Outcomes the decision must optimize |
| Disqualifiers | Conditions that remove an option |
| Reversibility | One-way door, two-way door, or staged |

## Option Set

Every decision artifact must include:

- Preferred option.
- At least two viable alternatives.
- Base case or current path.
- Wait or gather more evidence, if realistic.

If only one option is presented, the artifact is advocacy, not decision support.
