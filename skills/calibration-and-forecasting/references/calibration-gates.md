# Calibration Gates

## Ship Gate

- [ ] Forecast is a resolvable question with a deadline.
- [ ] Base rate or reason for no base rate is stated.
- [ ] Event probability is numeric.
- [ ] Source confidence is separate from event probability.
- [ ] At least one rival path is named.
- [ ] Update triggers are named before publication.
- [ ] Resolution source is identified.
- [ ] If a probability changed, the trigger evidence is cited.

## Scoring

Choose one scoring rule at project start and keep it stable. Brier-style scoring is appropriate for binary forecasts; ranked risk calls need a stated ranking metric. If the project cannot score a forecast later, recast it as a scenario or judgment instead of a forecast.

## Anti-Pattern Corrections

| Anti-pattern | Correction |
|---|---|
| "Likely to grow" | "We estimate 60-80% probability of growth by DATE, resolved by SOURCE." |
| "High confidence" | Separate event probability, source reliability, and analyst confidence. |
| Scenario A/B/C with no odds | Mark as scenario planning, or assign probabilities if decision use requires it. |
| Forecast overwritten after new evidence | Append update record; preserve prior probability. |
