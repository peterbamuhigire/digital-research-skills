# Shape Catalogue

## Shape Router

| Reader action | Analytic mode | Shape | Companion skills |
|---|---|---|---|
| Know fast | Descriptive/current | Current brief | `source-evaluation`, `executive-communication` |
| Decide | Advisory | Decision memo | `decision-support-analysis`, `executive-communication` |
| Monitor risk | Warning | Warning note | `analytic-tradecraft`, `calibration-and-forecasting` |
| Judge future | Estimative | Estimative memo | `analytic-tradecraft`, `calibration-and-forecasting` |
| Compare options | Evaluative | Options paper | `decision-support-analysis` |
| Verify allegations | Investigative | Investigation report | `source-evaluation`, `osint-investigation`, `evidence-claim-graph` |
| Track delivery | Status | Status report | `executive-communication` |
| Preserve knowledge | Reusable | Research report | `evidence-claim-graph`, `knowledge-productization` |
| Sell insight | Commercial | White paper / market analysis | `research-output-formats`, `knowledge-productization` |

## Shape Selection Rules

- If the reader must act now, use a brief or memo, not a long report.
- If the claim will be challenged, preserve audit trail in the body or appendix.
- If uncertainty is central, use estimative or warning shapes with probability language.
- If the output must become IP, use a reusable research report plus productization plan.
- If the audience is senior and time-constrained, put the answer first.
