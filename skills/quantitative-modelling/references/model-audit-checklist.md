# Model Audit Checklist

## Input Discipline

- [ ] Every source input has a source ID.
- [ ] Every assumption is labelled as assumption.
- [ ] Units are consistent.
- [ ] Time periods match or conversion is explained.
- [ ] Population and geography match the claim.

## Triangulation

Use more than one path when possible:

- Top-down estimate.
- Bottom-up estimate.
- Comparable benchmark.
- Observed transaction or usage data.
