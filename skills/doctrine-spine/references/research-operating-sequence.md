# Research Operating Sequence

## Canonical Sequence

| Stage | Purpose | Primary output |
|---|---|---|
| 1. Evidence discipline | Prevent hallucination and citation drift | Hard constraints |
| 2. Research design | Define question, scope, cohorts, methods | Research design note |
| 3. Collection | Gather sources by wave and cohort | Source registry |
| 4. Verification | Test source, quote, stat, and URL integrity | Verification manifest |
| 5. Claim graph | Link evidence to claims and gaps | Claim graph |
| 6. Reasoning | Test warrants, assumptions, and countercases | Argument map |
| 7. Tradecraft | Test hypotheses, uncertainty, bias, deception | Tradecraft record |
| 8. Calibration | Make forecasts resolvable and updatable | Forecast card |
| 9. Decision support | Convert findings into choices | Decision memo logic |
| 10. Report shape | Choose artifact structure | Shape selection note |
| 11. Productization | Package reusable knowledge | Asset manifest |
| 12. Export | Render and pack release | Release ledger |

## Crosswalk Rule

Every project can skip a stage only by recording why it is not applicable. Skipping is a waiver, not silence.
