# Claim Promotion Gate

Use before any claim becomes a finding, recommendation, key judgment, or executive takeaway.

## Promotion Checklist

- [ ] Claim has clear scope.
- [ ] Claim cites at least one source ID.
- [ ] Source tier and verification trail are present.
- [ ] Evidence is relevant and current enough for the claim.
- [ ] Warrant is explicit.
- [ ] Assumptions are named.
- [ ] Contradictory evidence has been checked.
- [ ] Claim status is not `untested`.
- [ ] If status is `synthesis` or `inference`, the output labels it as such.
- [ ] Confidence is proportional to evidence quality.

## Finding Template

| Field | Requirement |
|---|---|
| Finding | One sentence |
| Claim IDs | All supporting claims |
| Evidence limits | Main weakness |
| Confidence | high, medium, low, with reason |
| Decision implication | Why it matters |
| Recheck trigger | What evidence would change it |
