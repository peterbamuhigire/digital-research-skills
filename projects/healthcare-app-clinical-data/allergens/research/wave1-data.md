## Data Dictionary

| Column | Type | Notes |
|--------|------|-------|
| allergen_id | TEXT PK | System-assigned identifier |
| allergen_name | TEXT | Display name for patient/clinical use |
| allergen_kind | ENUM | DRUG_CLASS \| DRUG_SUBSTANCE \| FOOD \| ENVIRONMENTAL \| VENOM \| EXCIPIENT |
| rxnorm_concept_id | INTEGER FK | RxNorm concept ID; populated for all drug allergens |
| snomed_ct_concept | TEXT FK | SNOMED CT code (base code, no post-coordination); free-set |
| atc_codes_implicated | TEXT | Space-separated ATC classification(s) referenced in cross-reactivity literature |
| common_cross_reactions | TEXT | Markdown list; cites T1/T2 source; "(inference)" or "(synthesis)" where applicable |
| severity_typical | ENUM | MILD \| MODERATE \| SEVERE \| ANAPHYLACTIC; per WAO 2024 grading |
| common_manifestations | TEXT | Markdown list of clinical signs/symptoms; cites source |
| source_citations | TEXT | APA-style short citations; T1 first, then T2; no Wikipedia |
| code_system_version | TEXT | RxNorm release date or SNOMED CT edition used |
| code_accessed_date | TEXT | ISO 8601 date when codes were verified |
