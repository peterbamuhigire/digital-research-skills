## 2. Method

- **Desk screen (step 3).** For every candidate: default-branch HEAD SHA, SPDX key, stars, push date, archived flag and open-issue count from the GitHub API; the recursive file tree (counts of `SKILL.md`, script files and hook files); install lines extracted from the README; host names found in up to six `SKILL.md` files. Scripts were counted, never run.
- **Two depths.** *Screened* (20 candidates): the skill-shaped repositories relevant to at least one engine, plus the two new `anthropics/skills` folders and the ToxicSkills demonstration repository. These carry outbound-host notes and overlap paths from grep across the twelve public engines (`srs-skills`, `business-plan-skills`, `website-skills`, `social-media-skills`, `linux-skills`, `proposal-skills`, `digital-research-engine`, `chwezi-accounting-doctrine`, `chwezi-dev-engine`, `design-system-skills`, `windows-admin-engine-skills`, `chwezi-engine-agents`). *Triaged* (27 candidates): applications, agent harnesses, gateways, lists and packs outside the engines' domains. These carry API metadata, file-tree script presence and README install lines; outbound hosts and overlap are `NOT_ASSESSED` and each register row says "Triage only".
- **Re-check set.** The ten my-10-kaizen source repositories, compared with their pinned or studied commits: HEAD, releases, licence and repository security advisories.
- **Safety (step 5).** Static reading only against `skill-safety-gate.md`: hooks, curl-piped installers, credential requests, outbound model routing and instruction-override text were noted where seen. Items not read are `NOT_ASSESSED`.
- **Licence rules.** GPL-family and "all rights reserved" sources: ignore for reuse. `NOASSERTION` or no licence: ideas only. CC BY-NC: ideas only (non-commercial terms conflict with the MIT engines).
- **Limits.** The topic-search window is star-ranked, so small, well-made repositories are under-represented. Star counts moved by a few units between calls on the same day; the register records the value from the screening call.
