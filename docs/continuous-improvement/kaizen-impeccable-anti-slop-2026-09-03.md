# Kaizen Record: Impeccable-Derived Anti-Slop Overlay

**Date:** 2026-09-03
**Owner:** Digital Research Engine maintainer
**Source:** `impeccable-slop-page-2026-09-03`
**Re-audit:** 2026-10-03

## Aim

Strengthen anti-AI-slop controls for interfaces, websites, and design artifacts while giving the
other engines useful content/structure checks without importing visual taste as a universal rule.

The approved visual boundary is stricter: purple gradients, glassmorphism, neon glow, AI-beige
defaults, decorative editorial scaffolding, and decorative motion are no-ship choices for websites,
web products, design artifacts, and presentations. Functional state, accessibility, and data
encoding remain task-governed.

## Baseline

ME1-ME7 covered semantic repetition, artificial symmetry, over-explanation, inflated significance,
generic examples, rhetorical mannerisms, and insight-shaped filler. Visual engines already had
anti-convergence guidance, but the portfolio lacked one source-scoped contract for default
convergence, unearned hierarchy, decorative attention, placeholder material, copy tells, and
polish-covered delivery debt.

## PDSA experiment

- **Plan:** add AS1-AS7 to the shared gate; route the full overlay to web development, website, and
  design; route applicable checks to the remaining engines.
- **Do:** add source/evidence records, pressure fixtures, coverage validation, and domain adapters.
- **Study:** compare central coverage, native validators, routing precision, and false-positive
  exception handling. Treat unavailable browser/render/tool evidence as `NOT_ASSESSED`.
- **Act:** standardise the overlay only where the adapter preserves task, accessibility, safety,
  requirements, finance, legal, and operational function; roll back a local mapping if it causes
  false-positive harm.

## Measures and stop condition

| Measure | Target |
|---|---|
| AS1-AS7 coverage | 12/12 registered engine adapters |
| Pressure fixture | One observable case per AS check plus functional exceptions |
| Native gates | No new validator or routing failures |
| Evidence discipline | No universal-prevalence claim; unsupported visual judgement remains `NOT_ASSESSED` |
| Stop condition | Any adapter suppresses required repetition, accessibility, safety, traceability, or legally operative wording |

## Decision

Adopt AS1-AS7 as a scoped overlay. Keep Impeccable optional and source-bound; do not convert its
catalog into a mandatory dependency or an aesthetic blacklist.
