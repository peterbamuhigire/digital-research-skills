# Required Feature Set for World-Class Output

- Full-workflow orchestration from intake to final deliverable and evidence pack.
- Representative examples for each core deliverable family.
- Quality gates that block generic, ungrounded, or unverifiable output.
- Dated source and standards registers for volatile facts.
- Templates, checklists, and acceptance criteria that are reusable without rewriting the skill.
- Cross-engine handoff contracts for design, finance, documents, spreadsheets, security, and research where relevant.
- Negative examples and failure-mode handling for ambiguous, risky, or incomplete inputs.
- Professional finalization path: rendered output, audit log, reviewer notes, and release checklist.

## Domain-Specific Must-Haves

- Separate reusable engine, examples, and active projects more cleanly.
- Complete verification tooling for sources, quotes, statistics, archived URLs, images, and datasets.
- Add exemplar outputs for each research type/schema.
- Add analytic-tradecraft scoring fixtures and peer-review transcripts.
- Create source freshness and citation-density dashboards.
