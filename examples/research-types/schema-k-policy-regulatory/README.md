# Schema K Exemplar - Policy / Regulatory Research

Last verified: 2026-07-08
Benchmark: Policy memo with primary-law hierarchy and implementation analysis.

## Context

The policy brief maps legal authority, agency mandates, data/privacy constraints, fees, and implementation risks for a pilot. It uses primary sources before commentary.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Legal and policy source map | Statute, regulation, guideline, agency-source register |
| 2 | Operational interpretation | Mandate and implementation questions |
| 3 | Verification | Currency, citation, and authority checks |
| 4 | Synthesis | Risk, compliance conditions, and decision note |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| K-C1 | Primary authority outranks commentary. | Legal research rule | Mandatory |
| K-C2 | Policy intent is not implementation capacity. | Analytic rule | Enforced |
| K-C3 | Currency must be checked before release. | Compliance rule | Mandatory |

## Final Report Specimen

The regulatory section should answer what the pilot may do, who must approve it, what data it may process, and which unresolved interpretations need counsel or agency confirmation.

## Gate Verdict

Status: pass as exemplar. Live report fails if legal claims lack current primary authority.
