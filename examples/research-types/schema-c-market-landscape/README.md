# Schema C Exemplar - Market / Industry Landscape

Last verified: 2026-07-08
Benchmark: BCG-style market landscape with explicit evidence strength.

## Context

Chwezi Core Systems maps providers, funders, public agencies, and adjacent platforms around trade digitisation. The goal is to identify whether the proposed pilot fills a defensible gap.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Category map | Actor taxonomy and source register |
| 2 | White-space test | Adjacent products and donor programme scan |
| 3 | Verification | Entity existence and URL archive checks |
| 4 | Synthesis | Opportunity map with evidence confidence |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| C-C1 | The landscape includes public, donor, and private actors. | Fact pattern | Needs live actor registry |
| C-C2 | Differentiation depends on workflow integration. | Inference | Needs competitor evidence |
| C-C3 | Funding fit is separate from user fit. | Analytic judgment | Requires decision criteria |

## Final Report Specimen

The market gap should be defined by the operational job the pilot performs, not by the presence or absence of "trade platforms" as a broad category. A defensible landscape separates policy portals, payment rails, compliance tools, and trader-support services.

## Gate Verdict

Status: pass as exemplar. Live report fails if any named actor lacks a verified source and archive.
