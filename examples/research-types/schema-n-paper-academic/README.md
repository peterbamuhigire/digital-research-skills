# Schema N Exemplar - Paper / Journal Article, Academic Variant

Last verified: 2026-07-08
Benchmark: Journal-ready article using EQUATOR/PRISMA where relevant.

## Context

The academic paper presents a bounded study of digital trade facilitation evidence. If systematic-review methods are used, PRISMA 2020 governs reporting.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Search and screening | Database/search log and inclusion criteria |
| 2 | Extraction and appraisal | Evidence table and bias notes |
| 3 | Verification | PRISMA checklist and citation audit |
| 4 | Synthesis | Abstract, methods, results, discussion |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| N-C1 | Methods must be reproducible. | Reporting rule | Mandatory |
| N-C2 | Screening decisions need exclusion reasons. | PRISMA rule | Mandatory if systematic |
| N-C3 | Discussion must separate finding and implication. | Academic rule | Enforced |

## Final Report Specimen

The article should make a narrow, defensible contribution: what the evidence supports about pilot readiness, what it does not support, and which research design would close the remaining gap.

## Gate Verdict

Status: pass as exemplar. Live paper fails if PRISMA-relevant elements are absent from a systematic review.
