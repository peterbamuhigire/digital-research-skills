# Schema D Exemplar - Comparative / Benchmarking

Last verified: 2026-07-08
Benchmark: Gartner/Forrester-style comparison with transparent scoring rules.

## Context

The benchmark compares digital trade facilitation approaches across selected jurisdictions or programmes. Scoring is based on verified criteria, not impressionistic ranking.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Criteria design | Benchmark criteria and weighting rationale |
| 2 | Comparator scan | Evidence table for each comparator |
| 3 | Verification | Source and scoring audit |
| 4 | Synthesis | Comparative matrix and adoption lessons |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| D-C1 | Comparators must be matched by use case. | Method rule | Verified by design review |
| D-C2 | Scoring must expose weak evidence. | QA rule | Enforced in template |
| D-C3 | Best practice is context-dependent. | Analytic judgment | Requires caveats |

## Final Report Specimen

The benchmark should not crown a single winner. It should show which design patterns survive transfer to the pilot context and which depend on institutions, data access, or infrastructure the pilot may not have.

## Gate Verdict

Status: pass as exemplar. Live report fails if scores are not tied to source IDs and criteria definitions.
