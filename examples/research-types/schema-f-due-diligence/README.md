# Schema F Exemplar - Due Diligence

Last verified: 2026-07-08
Benchmark: Big Four / specialist investigations due-diligence memo.

## Context

The due-diligence question is whether a proposed implementation partner is suitable for the pilot. The exemplar separates corporate existence, ownership, adverse media, sanctions, capability, and conflicts.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Registry and identity | Entity profile and source hierarchy |
| 2 | Risk scan | Adverse media, sanctions, litigation, conflicts |
| 3 | Verification | Entity-name disambiguation and source checks |
| 4 | Synthesis | Risk rating and decision conditions |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| F-C1 | Entity identity must be verified before risk analysis. | Control rule | Mandatory |
| F-C2 | Adverse media is a lead, not a verdict. | Method rule | Requires triangulation |
| F-C3 | Beneficial ownership gaps affect confidence. | Gap | Must be disclosed |

## Final Report Specimen

The risk conclusion should be written as a decision aid: what is known, what remains unverified, which gaps are material, and which conditions should be met before contracting.

## Gate Verdict

Status: pass as exemplar. Live report fails if entity names, registries, or sanctions checks are not independently verified.
