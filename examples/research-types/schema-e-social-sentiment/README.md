# Schema E Exemplar - Social-Media / Sentiment Research

Last verified: 2026-07-08
Benchmark: Investigative social-listening brief with provenance and bias caveats.

## Context

The study examines public online discussion around cross-border trader pain points. It treats social content as leads and attributed evidence, not representative population measurement unless a defensible sampling frame exists.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Keyword and platform map | Query log and collection boundaries |
| 2 | Theme coding | Sentiment and issue taxonomy |
| 3 | Verification | Bot/repost/provenance checks |
| 4 | Synthesis | Signal, caveat, and follow-up evidence needs |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| E-C1 | Social posts can identify issues for follow-up. | Method claim | Valid if attributed |
| E-C2 | Social volume is not population prevalence. | Limitation | Must be stated |
| E-C3 | Screenshots are weak without provenance. | Verification rule | Apply media forensics |

## Final Report Specimen

Social evidence is useful here as an issue-discovery layer. It should not be converted into a prevalence claim unless the collection frame, de-duplication, and source provenance are strong enough to support that claim.

## Gate Verdict

Status: pass as exemplar. Live report fails if social screenshots are treated as verified facts without provenance.
