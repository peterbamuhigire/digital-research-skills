# Schema B Exemplar - Single-Cohort Deep Dive

Last verified: 2026-07-08
Benchmark: Specialist user-research memo with traceable evidence.

## Context

The selected cohort is informal traders who would be asked to use a proposed digital trade service. The deliverable explains their workflow, constraints, language needs, trust barriers, and decision triggers.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Cohort profile | Journey map and source register |
| 2 | Contradiction search | Evidence against assumed digital readiness |
| 3 | Verification | Quote checks and respondent/source provenance |
| 4 | Synthesis | Cohort-specific adoption conditions |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| B-C1 | Traders face administrative and information frictions. | Synthesis | Needs source IDs |
| B-C2 | Adoption depends on practical value at the border. | Inference | Requires interview support |
| B-C3 | Language and assistance needs are design constraints. | Assumption | Verify by fieldwork |

## Final Report Specimen

The cohort should not be treated as "digitally excluded" or "digitally ready" as a category. The right decision question is narrower: what task would a trader trust the service to perform during a high-pressure border crossing?

## Gate Verdict

Status: pass as exemplar. Live use requires consent records, source tiers, and no unattributed respondent quotes.
