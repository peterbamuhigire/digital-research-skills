# Schema P Exemplar - PhD Dissertation, Academic Variant

Last verified: 2026-07-08
Benchmark: Doctoral dissertation with original contribution, defensible method, and viva-ready argument.

## Context

The dissertation develops and tests a framework for digital public-service adoption in cross-border trade contexts.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Literature architecture | Theoretical gap and conceptual model |
| 2 | Research design | Case selection, method, ethics, data plan |
| 3 | Verification | Citation, data, and originality audit |
| 4 | Synthesis | Findings, contribution, limitations, defence brief |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| P-C1 | Original contribution must be explicit. | Doctoral rule | Mandatory |
| P-C2 | Method must answer the research question. | Quality rule | Mandatory |
| P-C3 | Rival explanations must be handled. | Argument rule | Enforced |

## Final Report Specimen

The dissertation should make a claim that is narrower than advocacy and stronger than description: a tested explanation of why some digital facilitation designs become usable in real institutional settings and others do not.

## Gate Verdict

Status: pass as exemplar. Live dissertation fails if contribution, method, and evidence chain are not examinable.
