# Research Type Exemplars

Last verified: 2026-07-08

This directory contains sanitized, complete workflow exemplars for the 19 supported schemas. Each schema folder includes the five minimum release artefacts: context, wave log, evidence table, final-report specimen, and evidence/slop gate verdict.

The exemplars use the Chwezi Core Systems running example in `docs/world-class-exemplars/running-example.md`. They teach structure and quality gates; they do not assert live facts.
