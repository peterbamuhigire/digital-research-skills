# Schema J Exemplar - Trends Research

Last verified: 2026-07-08
Benchmark: Decision-grade trend brief with indicators and confidence language.

## Context

The trends brief asks which changes could affect a digital trade pilot over the next 12 to 24 months. It separates observed trend, weak signal, driver, and scenario.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Signal scan | Trend and weak-signal register |
| 2 | Driver analysis | Political, technology, funding, user-behaviour drivers |
| 3 | Verification | Source freshness and indicator checks |
| 4 | Synthesis | Scenarios, indicators, and confidence levels |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| J-C1 | Trends require dated evidence. | Method rule | Enforced |
| J-C2 | Weak signals cannot be written as forecasts. | Anti-pattern | Enforced |
| J-C3 | Indicators make trend monitoring actionable. | Method rule | Valid |

## Final Report Specimen

The brief should state what is already visible, what remains uncertain, and which indicators would change the recommendation. Trend language must carry time horizon and confidence.

## Gate Verdict

Status: pass as exemplar. Live report fails if stale sources are used for current trends without warning.
