# Schema L Exemplar - Thesis, Academic Variant

Last verified: 2026-07-08
Benchmark: Oxford/Cambridge/LSE-quality master's thesis structure with transparent method.

## Context

The thesis studies digital trade facilitation as a governance and user-adoption problem. The exemplar defines research question, literature frame, methodology, findings, and limitations.

## Wave Log

| Wave | Purpose | Output |
|---|---|---|
| 1 | Literature and theory map | Search log and conceptual framework |
| 2 | Method design | Case selection, data sources, ethics note |
| 3 | Verification | Citation and quote audit |
| 4 | Synthesis | Argument, contribution, limitations |

## Evidence Table

| Claim ID | Claim | Evidence type | Verification status |
|---|---|---|---|
| L-C1 | Research question must be answerable by the method. | Academic rule | Enforced |
| L-C2 | Contribution must be bounded. | Academic rule | Enforced |
| L-C3 | Limitations are part of credibility. | Quality rule | Mandatory |

## Final Report Specimen

This thesis would argue that digital facilitation succeeds only when user tasks, agency incentives, and evidence systems align. The contribution is a bounded decision framework, not a universal theory of trade digitisation.

## Gate Verdict

Status: pass as exemplar. Live thesis fails if it lacks method justification, citation audit, or originality claim.
